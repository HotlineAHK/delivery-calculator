# Калькулятор доставки (Django)

Учебная практика: веб-приложение считает стоимость доставки по данным из формы. Без аутентификации, один пользователь.

## Что делает

- Форма заявки: ФИО отправителя, телефон, город отправки, город получения, вес (кг), тип доставки, согласие с условиями.
- Расчёт стоимости: 300 руб. базовая ставка + 30 руб. за каждый кг, множитель по типу доставки (standard x1.0, express x1.5, same_day x2.0), результат округляется до 2 знаков.
- Валидация: вес от 0.1 до 100 кг, города не должны совпадать, для express вес не больше 20 кг, телефон 10-15 цифр.
- При ошибках форма возвращается с сохранёнными данными и подсветкой невалидных полей.

## Дополнительная фича

Выбрал «История расчётов»: модель `Order` (SQLite), успешные заявки сохраняются в БД, на главной странице выводятся последние 5 расчётов. Из-за модели форма сделана через `ModelForm` вместо `Form` (это часть выбранной фичи).

## Запуск

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Открыть http://127.0.0.1:8000/

## Тесты

```
python manage.py test
```

11 тестов: расчёт стоимости по типам доставки, диапазон веса, совпадение городов, лимит express, обязательное согласие, сохранение данных при ошибке, история из 5 записей.
